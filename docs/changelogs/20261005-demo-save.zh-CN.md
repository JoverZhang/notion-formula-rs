# 修复补全列表打开时的公式保存

[English](20261005-demo-save.md)

- Type: Fixed
- Component: Vite 示例

## Summary

公式补全列表打开时，点击 Save 会保持按钮位置稳定，直到点击完成。此前，编辑器失焦可能
关闭补全列表，使页面在鼠标按下和松开之间移动，导致公式未保存。键盘保存仍可正常使用。

## Compatibility notes

无需修改 API 或已保存的公式。
