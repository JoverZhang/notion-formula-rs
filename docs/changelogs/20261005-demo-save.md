# Keep formula saving reliable with completion open

[简体中文](20261005-demo-save.zh-CN.md)

- Type: Fixed
- Component: Vite demo

## Summary

Clicking Save while formula completion is open keeps the button in place until the click
completes. Previously, editor blur could close completion and move the page between mouse
press and release, leaving the formula unsaved. Keyboard saving continues to work.

## Compatibility notes

No API or stored-formula changes are required.
