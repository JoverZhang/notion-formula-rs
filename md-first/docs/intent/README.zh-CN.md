# Intent

[English](README.md)

编译器是人类与计算机沟通的桥梁。高级语言让我们能够表达更抽象的概念。针对具体领域设计的 DSL，往往能以更精确、更易读的方式表达该领域的规则。

在 vibe coding 时代，构造更复杂的程序是必然趋势，就像从汇编走向高级语言一样，甚至会带来更大的跨越。我们也需要更有表达力的语言，才能理解和驾驭这些程序。

面向抽象编程的难处，常常在于维护抽象本身。项目不断变化，代码就需要不断整理和重构，这在过去很昂贵。vibe coding 有望降低这部分成本，让 human 和 agent 都能先把设计想清楚，再逐步处理实现中的细节。
